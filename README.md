# 图标

图标合集（策略组图标库 JSON），三个文件均同时包含 Emby 与任天堂（Nintendo / Switch）图标。

| 文件 | 来源 | 图标数 | 说明 |
| --- | --- | --- | --- |
| Quremini.json | Koolson/Qure | 347 | Emby、Nintendo 正名图标 |
| icons-all.json | fmz200/wool_scripts | 1608 | Emby 30 个（多为各服定制款）、switch |
| ligeicon.json | lige47/QuanX-icon-rule | 1025 | Emby 8 个（含 SNTP 守候款）、Switch |

在客户端的图标库中添加对应文件的 raw 链接即可使用。
